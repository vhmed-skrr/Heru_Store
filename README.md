# Heru Store — المتجر الإلكتروني الرسمي
وصف قصير: متجر إلكتروني مصري للمنتجات الشبابية يقدم تجربة مستخدم سلسة وتصاميم عصرية.

## 🛠️ Tech Stack
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript (بدون إطارات عمل معقدة لضمان السرعة المطلقة).
- **Backend:** Supabase (PostgreSQL + Auth + Storage).
- **Hosting:** Vercel (Edge Network deployments).
- **Images:** Cloudinary (صيغ WebP و تحجيم ذكي).
- **Payment:** Fawry + InstaPay + Cash on Delivery (الدفع عند الاستلام).

## 📋 Requirements
قبل البدء بتثبيت وإعداد المشروع، تأكد من امتلاكك للمتطلبات التالية:
- متصفح حديث يدعم ميزات الـ JS الحديثة (Chrome 90+, Firefox 88+, Safari 14+).
- حساب **Supabase** (مجاني للأبد لإدارة البيانات: [supabase.com](https://supabase.com)).
- حساب **Vercel** (مجاني للاستضافة: [vercel.com](https://vercel.com)).
- حساب **Cloudinary** (مجاني لإدارة الصور: [cloudinary.com](https://cloudinary.com)).

## 🚀 Setup من الصفر (10 دقائق)
في غضون 10 دقائق يمكنك الحصول على نسختك الحية تعمل بامتياز:

1. **إعداد حساب وقاعدة Supabase:**
   - قم بإنشاء مشروع جديد في Supabase.
   - اذهب إلى نافذة الـ `SQL Editor` وقم بلصق محتوى ملف `schema.sql` أو قم بتنفيذ الجداول (Products, Categories, Orders, Settings, Coupons).
   - احصل على الـ `Project URL` والـ `anon public key` من إعدادات API.

2. **تهيئة الصور (Cloudinary):**
   - افتح حساب في Cloudinary.
   - اصنع `Upload Preset` جديد بتصريح `Unsigned` من الإعدادات (ليسمح بالرفع من المتصفح مباشرة للوحة التحكم المخصصة).
   - احفظ اسم الـ `Cloud Name` الخاص بك.

3. **النشر السريع (Vercel):**
   - ارفع الكود الخاص بك للمستودع إلى GitHub.
   - ادخل على لوحة تحكم Vercel وانقر `Add New Project` وقم باستيراد مستودعك.
   - أثناء الإعداد، أضف المتغيرات السرية (Environment Variables) كما هي موضحة في الجدول بالأسفل.
   - انقر `Deploy`، وخلال ثوانٍ ستحصل على رابط متجرك الحي!

## 🔑 Environment Variables
ضع هذه المتغيرات بشكل سري في إعدادات مساحات (Vercel) الخاصة بك:

| المتغير | الوصف | أين تجده |
|---------|-------|----------|
| `SUPABASE_URL` | رابط الوصول لقاعدة بياناتك | Supabase > Project Settings > API |
| `SUPABASE_ANON_KEY` | مفتاح الواجهة العام المجهول | Supabase > Project Settings > API |
| `CLOUDINARY_CLOUD_NAME` | اسم حسابك التعريفي السحابي | Cloudinary > Dashboard |

## 🗄️ Database
- **كيفية تشغيل schema.sql:** قم بنسخ محتوى الملف ولصقه كاملاً في الـ SQL Editor عبر لوحة Supabase وانقر `Run`.
- **كيفية إضافة أول منتج:** ادخل إلى لوحة الآدمن في متجرك، توجّه إلى قسم "إدارة المنتجات"، ثم انقر "+ منتج جديد".
- **كيفية إنشاء أول Admin User:** في Supabase، اذهب إلى التبويب `Authentication` → `Users` وأضف مستخدم برقم سري قوي (سيسمح لك بتسجيل الدخول كأدمن لاحقاً).

## 👨‍💼 Admin Panel
- **رابط الدخول:** `/admin` 
- **كيفية إنشاء الحساب الأول:** كما هو موضح بالأعلى عبر الـ Authentication بـ Supabase Auth.
- **دليل استخدام كل قسم:**
  - *لوحة المؤشرات:* نظرة مالية مبسطة وعرض سريع لآخر التحركات والطلبات الحية.
  - *سجل الطلبات:* تغيير حالات التوصيل واختصار لتوليد وتصدير الطلبات CSV.
  - *إدارة المنتجات:* رفع الصور بالربط العضوي المباشر مع حساب الـ (Cloudinary) و ضبط الخوارزميات (السعر، المخزون، ووسم الظهور).

## 🛒 User Journey
1. **التصفح (`/shop`):** يرى العميل الكتالوج ويقوم بفرز المنتجات بالقسم أو السعر.
2. **شاشة المنتج (`/product?id=`):** يعاين الصور بدقة وحرية في معرض الستينيات (Lightbox) ويختار الكمية ويضيف للسلة.
3. **السلة (`/cart`):** مُعالجة محلياً `localStorage` للسرعة وتتجاوب حياً مع شريط الملاحة.
4. **الدفع (`/checkout`):** يعبئ نموذجًا دلاليًا (A11y Accessible forms)، ويرسل الطلب لـ Supabase لتتدفق رسالة طلب آليه عبر تنسيق WhatsApp.
5. **شاشة النجاح (`/confirmation`):** رسالة شكر وإرشادات ورقم مرجعي للمتابعة.

## 💳 Payment Methods
يتم توجيه وتسهيل الدفع من خلال صفحة الـ `checkout.html` وسكربتاتها البرمجية:
- **كاش عند الاستلام (COD):** يُطبع في الفاتورة للمندوب لتحصيل الدفع يدوياً عند نقطة تسليم الطرد للمستلم بالمنزل.
- **InstaPay:** يُوجه العميل لإرسال المبالغ مقدماً مع طلب إرفاق إيصال التحويل عبر شاشة الواتساب لاحقاً لتأكيد الحجز.
- **Fawry:** يُبرمج لإصدار رقم مرجعي (هو ذاته الـ Order Number) ليقوم العميل بالدفع في أي نقطة فورية بناءً عليه.

## 🔧 Common Tasks
- **إضافة منتج جديد:** يدوياً عبر لوحة الإدارة (`/admin`).
- **تغيير حالة طلب:** من تبويب 'الطلبات والمبيعات' في الـ `admin`.
- **إضافة كوبون خصم:** عبر التوجه لموديول 'محرك الكوبونات'.
- **تغيير إعدادات المتجر:** خيار 'الإعدادات العامة' في `/admin` لحفظ وحقن رقم الواتساب ورقم مقبض مسار الـ (Preset) للـ Cloudinary.
- **رفع صورة منتج:** الرفع تلقائي ومدمج بلوحة التحكم، وما عليك سوى السحب والإسقاط (Drag & Drop) لأي ملف.

## 🚨 Emergency Playbook (خطط التعافي من الكوارث)

تم تخطيط هذه السيناريوهات لضمان عودة المتجر للعمل في أسرع وقت.

### السيناريو 1: تعطل Supabase أو فقدان البيانات
- **الاحتمالية:** منخفضة جداً (SLA 99.9%).
- **التعافي السحابي (Cloud Recovery):** تقوم Supabase أوتوماتيكياً بعمل Backups يومية لقواعد البيانات.
- **إجراء وقائي (يدوي):**
  - **أسبوعياً:** من بوابة الإدارة في المشروع المباشر (`/admin`) → انقر زر `تصدير CSV` واحفظ مخزون الطلبات بأمان.
  - **شهرياً:** الدخول للوحة Supabase الرئيسية → Database → Backups → Download SQL dump للاحتفاظ بنسخة مادية.

### السيناريو 2: تعطل Vercel
- **الاحتمالية:** نادرة جداً.
- **التعافي السريع:** الكود بأمان على مستودعات GitHub، من السهل جداً النشر على خادم آخر في أقل من 10 دقائق:
  1. توجه إلى Netlify عبر `netlify.com` وأضف موقع جديد (`New site`).
  2. اختر "Import from GitHub".
  3. انتظر لمدة تصل إلى دقيقتين حتى يعود الرابط الجديد للفعالية التامة.

### السيناريو 3: خطأ في النشر يكسر الموقع
- **الاحتمالية:** يمكن توقعها من المطور.
- **الحل:** التراجع الفوري (Vercel Instant Rollback).
- **خطوات الإجراء:** 
  1. في صفحة `Deployments` في Vercel Dashboard الخاصة بهيرو.
  2. اختر آخر Deployment كانت تعمل بشكل جيد والنقر على نقاط الخيارات. 
  3. انقر تفعيل `Promote to Production`. (يعود المتجر للحياة في أقل من دقيقتين).

### السيناريو 4: توقف Cloudinary أو فقدان المخزون
- **الحل:** يتم إنشاء `Cloudinary Account` آخر مجاني ومستقل (مساحة 25 جيجا تكاليف منعدمة). 
- يتم التعديل السريع لـ `CLOUDINARY_CLOUD_NAME` داخل متغيرات الـ Vercel Environment، وتُخزن الصور بمعرفاتها (IDs) مباشرة لا على الخوادم لدينا.

### السيناريو 5: نسيان كلمة سر الإدارة (Admin)
- **الحل 1:** Supabase Auth → Authentication → Users → Reset Password. 
- **الحل 2:** Supabase Dashboard → SQL Editor → نفذ استعلام تحديث `UPDATE auth.users SET password...`.

## 📊 Analytics
المتجر مجهز بشكل كامل وبالمجان لربط المقاييس عن طريق **Vercel Web Analytics** و **Speed Insights**.
- **كيفية الاستخدام والرؤية:** ادخل على حساب Vercel وانقر على التبويبات العلوية ذات الصلة. سترى عدد الزائرون، والدول، والصفحات الأكثر زيارة. تعمل الأدوات بشكل دائم وسلس جداً في الخلفية لكونها لا تستخدم ولا تعتمد بالأساس على الكوكيز التتبعية (Cookieless Analytics).

## 🔄 Deployment
دورة النشر الكاملة تعتمد على استراتيجية الفروع والتحديث المستمر بلا عبث بميدان الإنتاج الحقيقي!
1. أخذ مسار فرعي جديد وتسميته (`git checkout -b feature/[feature-name]`).
2. برمج ميزاتك باطمئنان واعتمد التغييرات بـ `git commit & push`.
3. ارفع الفرع لـ `develop` عبر إجراء دمج **Pull Request**.
4. اختبر على الـ Preview URL الخاص بـ Vercel (والذي يطرح بشكل أوتوماتيك).
5. حال الطمأنينة الكاملة، يتم الدمج (Merge) للرئيسية لفرع الـ `main`. وفي ظروف لا تتعدى ה(60 ثانية) Vercel تنشر التحديث للعملاء أوتوماتيكياً.
